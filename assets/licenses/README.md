# Font licenses

This directory contains license texts for fonts that are embedded in the
generated ROM images or distributed with the repository.

| File | Covers | Embedded in |
|---|---|---|
| `CREDITS` | X11-style licenses for Daewoo `hanglm16` and Academia Sinica `gb16st` | `EmbFont16.bin` |
| `LICENSE_UNIFONT` | SIL Open Font License 1.1 for GNU Unifont JP | `EmbFont16Uni.bin` |

Public-domain sources do not require a license text:

- milkjf fonts (`assets/yaft/fonts/milkjf/`)
- JIS X 0213 BDFs (`assets/misc/`)

See `assets/misc/README.md` and the `README`/`COPYING` files in each
submodule for source details.

The project source code itself is licensed under the MIT License; see
`../../LICENSE`.
